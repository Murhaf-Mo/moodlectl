# Agent workflows

For requests to review, edit, remove, or invalidate quiz questions, or correct
grades after submissions, read
[moodle-quiz-question-remediation](moodlectl/agent_skills/moodle-quiz-question-remediation/SKILL.md).
It covers fixed and randomized quizzes before and after attempts; review flags do
not imply full credit. The default view uses original Moodle previews.

Installed agents can discover the same instructions with `moodlectl skills list`
and `moodlectl skills show moodle-quiz-question-remediation`. Use
`moodlectl skills path moodle-quiz-question-remediation` to locate supporting files.
